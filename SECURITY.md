# Security Policy

Injekta stores health-related data, so please report problems privately.

## Reporting a vulnerability

Use GitHub's private reporting: go to the **Security** tab of this repo and click **Report a vulnerability**. If that isn't available, email shinni@tutamail.com.

Please don't open a public issue or post details in a Discord server before it's fixed.

Include:

- What the problem is and which command or file it involves
- Steps to reproduce
- What an attacker could see or change

## What counts

Things we care most about:

- One user reading, changing or deleting another user's logs or schedule
- Admins getting around `/privacy` and seeing data without permission
- Leaking doses, medication or legs in bot logs or channel messages
- A way to tell whether someone uses the bot when they shouldn't be able to
- Exposed bot tokens or database access

## What to expect

This is a one-person project. I'll try to reply within 7 days and keep you updated until it's fixed. Credit is given if you want it.

## Supported versions

Only the latest commit on `main` is supported.
